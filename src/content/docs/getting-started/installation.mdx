## Install

`lit` is a peer dependency, so your app shares one copy with the components.

<Code language="bash" code={`npm install @tweakpad/ui lit`} />

## Register the elements

Import the design tokens once, then define every element. Registration is a side effect, so it belongs in your app's entry module.

<Code language="typescript" code={`import '@tweakpad/ui/styles.css';
import '@tweakpad/ui/register';`} />

Then use the elements in your markup:

<Code code={`<tp-field label="Email">
  <tp-input name="email" type="email" required></tp-input>
</tp-field>

<tp-button type="submit">Continue</tp-button>`} />

## Entry points

| Import | Contents |
| --- | --- |
| `@tweakpad/ui` | Component classes and utilities, without side effects |
| `@tweakpad/ui/register` | Defines every component |
| `@tweakpad/ui/widgets` | Widget classes: color picker, easing editor, flow, emoji picker and text editor |
| `@tweakpad/ui/register/widgets` | Defines every widget |
| `@tweakpad/ui/emoji` | Emoji data types, lookup helpers and the Emojibase adapter for the emoji picker |
| `@tweakpad/ui/text-editor` | Engine adapters, built-in tools, default layouts, strings and types for the text editor |
| `@tweakpad/ui/icons/<name>` | Individual icons |
| `@tweakpad/ui/styles.css` | Design tokens and page defaults |

Widgets are opt-in: neither `@tweakpad/ui` nor `@tweakpad/ui/register` includes them. The <a href={siteUrl('/docs/widgets/text-editor')}>text editor</a> also needs an editing engine, Tiptap or Lexical, that your app installs; the library depends on neither.

## Frameworks

The elements work in any framework that renders custom elements. For React and Vue the package also ships components that wrap them, typed from each element, and for Preact, Solid, Svelte and Vue templates, types for the elements' own tags.

| Import | Contents |
| --- | --- |
| `@tweakpad/ui/react`, `@tweakpad/ui/widgets/react` | React 19 components, one per element |
| `@tweakpad/ui/vue`, `@tweakpad/ui/widgets/vue` | Vue 3 components with `v-model`, one per element |
| `@tweakpad/ui/react/jsx` | Types for `<tp-…>` tags in React |
| `@tweakpad/ui/vue/elements` | Types for `<tp-…>` tags in Vue templates |
| `@tweakpad/ui/preact`, `/solid`, `/svelte` (and `/widgets/…`) | Types for `<tp-…>` tags in those frameworks |

<Code language="typescript" code={`import '@tweakpad/ui/styles.css';
import { Checkbox, Dialog, Button } from '@tweakpad/ui/react';

<Checkbox checked={checked} onCheckedChange={(event) => setChecked(event.detail.value)}>
  Snap to grid
</Checkbox>;`} />

A component defines its element when it first renders, and importing one bundles only that element. <a href={siteUrl('/docs/getting-started/frameworks')}>Frameworks</a> covers events, controlled values, slots and server rendering in each framework.

## Browser support

Current versions of Chrome, Edge, Firefox and Safari.
