Tweakpad UI is a library of custom elements. Each component is a real HTML element, so the same markup works in plain HTML, Astro, React, Vue, Svelte or anything else that renders the DOM.

## How the site is organized

- **Docs** covers installation, theming and every foundational component, with live examples you can switch between default and compact density, and copy.
- **Patterns** are recipes: complete compositions such as a sign-in screen or password recovery. They are not components; copy one and make it yours. Each component page links to the patterns that use it.
- **DevKit** is a tweak panel built on the library: bind your own objects to sliders, toggles, colors and graphs, and tune them while your app runs. It is its own package, `@tweakpad/devkit`, documented in [DevKit](../devkit/).

## Principles

Components own their accessibility semantics, keyboard behavior and states. Styling flows through inherited `--tp-*` design tokens, so a theme is a set of custom properties rather than overrides of component internals. The theme switcher in the header uses the library's own `tp-theme-switcher`, and switching it re-themes this whole site, demos included.
